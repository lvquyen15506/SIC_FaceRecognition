# 🤖 BMAD CORE AGENTS SUITE

### 🕵️‍♀️ Mary (Business Analyst)
- **Nhiệm vụ**: Phân tích bài toán, thu thập yêu cầu và bóc tách ý tưởng sản phẩm eKYC.

### 📋 John (Product Manager)
- **Nhiệm vụ**: Lập PRD, viết User Stories (`As a... I want... So that...`), thiết lập Acceptance Criteria cho từng Sprint.

### 🎨 Sally (UX Designer)
- **Nhiệm vụ**: Thiết kế luồng người dùng (User Flow), wireframe tương tác camera real-time và giao diện eKYC ngân hàng.

### 🏗️ Winston (System Architect)
- **Nhiệm vụ**: Thiết kế kiến trúc kỹ thuật bọc quanh `src/`, quy định API Schema (FastAPI/WebSocket), thiết kế CSDL.

### 💻 Amelia (Senior Developer)
- **Nhiệm vụ**: Lập trình Web API & Frontend dựa trên thiết kế của Winston và PRD của John, kết nối với `src/`.
